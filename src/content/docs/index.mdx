## Sentences that run

Some sentences on the tool pages carry a small mark such as "checked with archstrict".
That sentence is tied to a command in this repository.
The build runs the command and compares its exit code and output with what the sentence says.
If the tool changes and the sentence stops being true, the check fails and names the sentence.
