## ツール同士の使い方

<DogfoodGraph lang="ja" />

<ToolSection lang="ja" section="cli">
下のバージョンとインストールコマンドは、手で書いたものではなく npm レジストリから読んだ値です。
各セクションのカードの説明は、各ツールの日本語のページから読んでいます。
</ToolSection>

<ToolSection lang="ja" section="gems">
下のバージョンとインストールコマンドは、RubyGems から読んだ値です。
</ToolSection>

<ToolSection lang="ja" section="skills">
これらにはパッケージのレジストリがありません。
下のバージョン、ライセンス、スキルの名前は、既定のブランチの最新のコミットにあるリポジトリ自身のマニフェスト、スキルのファイル、README、LICENSE から読んでいます。
インストールコマンドは、README と照らし合わせて確かめています。
どのエージェントに対応するかは、各ページに書いてあります。
</ToolSection>

<ToolSection lang="ja" section="mods">
どれも Claude Code のプラグインで、README では Claude Mod と呼び、トランスクリプトの横にペインを描きます。
Claude Code でしか動かず、どれも `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` が必要です。
情報は、上のプラグインとスキルと同じ方法で各リポジトリから読んでいます。
</ToolSection>

## 実行される文

ツールのページの文には、「確認に使用 archstrict」のような小さな印が付くものがあります。
その文は、このリポジトリのコマンドに結び付いています。
ビルド時にそのコマンドを実行し、終了コードと出力を文の内容と照らし合わせます。
ツールが変わって文が正しくなくなると、検査が失敗し、その文を指摘します。
