archstrict は、ArchUnit と同じ意味で、TypeScript のモジュール境界を検査します。
モジュールは、コードベースの残りに公開用のファイルを 1 つだけ見せ、それを飛び越える import は違反になります。
違反の報告には、規則の ID、場所、理由、直すためのコマンドが付くので、エージェントが自分の誤りを自分で直せます。

## フィクスチャで試す

このリポジトリの `fixtures/` に、小さなプロジェクトが 2 つあります。
1 つ目では、あるファイルが `billing/rounding.ts` を直接 import していて、`billing` モジュールの公開面を飛び越えています。

2 つ目のプロジェクトでは、同じコードが `billing/index.ts` 経由で import しています。
