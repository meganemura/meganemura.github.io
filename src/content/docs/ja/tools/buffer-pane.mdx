次に頼みたいことは、エージェントが長いターンを実行している間によく思いつきます。
プロンプト欄のテキストは、Enter を 1 回押すだけでエージェントに届きます。
そして Enter を押すと、ターンが中断されるか、テキストがキューに入ります。
buffer-pane は、準備ができるまでそのテキストをためておくペインをトランスクリプトの横に開く、Claude Code のプラグイン (Claude Mod) です。
Claude Code のターミナルセッションでしか動きません。
プリントモード (`-p`) にはペインがないからです。

## 特徴

- **ターンの実行中にブロックを書く。**
  最後の入力欄に書いて Enter を押すと、ブロックが追加されます。
  空行でバッファがブロックに分かれます。
  このバージョンでは、1 つのブロックは 1 行です。
- **`[+]` でプロンプト欄を埋める。**
  ブロックがプロンプト欄のテキストをすべて置き換え、ペインにはそのブロックが `✓` 付きで残ります。
  プラグインはプロンプト欄を読めないので、`[+]` はプロンプト欄が空のときに押してください。
- **`[>]` でブロックを送る。**
  ブロックは次のプロンプトとしてエージェントに届き、ペインから消えます。
  ターンの実行中は、ターンが終わるまでキューで待ちます。
- **並べ替えと削除。**
  `[^]` と `[v]` でブロックを動かし、`[x]` で削除します。
- **ディレクトリごとのバッファ。**
  Claude Code のプラグイン用ストレージが、バッファを `buffer:<working directory>` というキーで保存します。
  そのため、バッファはセッションをまたいで残り、ディレクトリごとに別々になります。

## エージェントでの使い方

エージェントがブロックを目にするのは、送ったときだけです。
`[>]` はブロックを次のプロンプトとして送ります。
`[+]` はブロックをプロンプト欄に入れるので、内容を読んでから Enter で送ります。
それまでテキストはペインにとどまり、ターンを中断しません。

## はじめかた

buffer-pane には、Claude Code 2.1.273 以降と `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` が必要です。

```sh
claude plugin marketplace add meganemura/buffer-pane
claude plugin install buffer-pane@buffer-pane
```

`/buffer-pane` と入力するとペインが表示され、もう一度入力すると隠れます。
function hooks の API は Claude Code のリリースごとに変わることがあるので、README はこのプラグインを早期アクセス版と位置付けています。
