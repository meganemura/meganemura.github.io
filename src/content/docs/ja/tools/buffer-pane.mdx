次の依頼の思いつきは、エージェントが長いターンを実行している間によく浮かびます。
プロンプト欄の文は Enter 1 つでエージェントに届き、Enter はターンを中断するか、文を待ち行列に入れます。
buffer-pane は、準備ができるまでその文をためておくペインをトランスクリプトの横に開く、Claude Code のプラグイン（Claude Mod）です。
Claude Code の、ターミナルのセッションでしか動きません。
プリントモード（`-p`）にはペインがないからです。

## 特徴

- **ターンの実行中にブロックを書く。**
  最後の入力欄に書いて Enter を押すと、ブロックが加わります。
  空行がバッファをブロックに分け、この版では 1 つのブロックは 1 行です。
- **`[+]` でプロンプト欄を埋める。**
  ブロックはプロンプト欄の文をすべて置き換え、ペインには `✓` 付きで残ります。
  プラグインはプロンプト欄を読めないので、`[+]` は欄が空のときに押します。
- **`[>]` でブロックを送る。**
  ブロックは次のプロンプトとしてエージェントに届き、ペインから消えます。
  ターンの実行中は、ターンが終わるまで待ち行列で待ちます。
- **並べ替えと削除。**
  `[^]` と `[v]` でブロックを動かし、`[x]` で消します。
- **ディレクトリごとのバッファ。**
  Claude Code のプラグインのストアが、バッファを `buffer:<working directory>` というキーで持つので、セッションをまたいで残り、ディレクトリごとに別のバッファになります。

## エージェントでの使い方

エージェントがブロックを目にするのは、送ったときだけです。
`[>]` は次のプロンプトとして送り、`[+]` はプロンプト欄に入れるので、読んでから Enter で送ります。
それまで文はペインにとどまり、ターンを中断しません。

## はじめかた

buffer-pane には、Claude Code 2.1.273 以降と `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` が必要です。

```sh
claude plugin marketplace add meganemura/buffer-pane
claude plugin install buffer-pane@buffer-pane
```

`/buffer-pane` と打つとペインが表示され、もう一度打つと隠れます。
function hooks の API は Claude Code のリリースの間で変わることがあるので、README はこのプラグインを早期アクセスとしています。
