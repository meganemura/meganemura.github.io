draft-pane は、少ないターン数で、下書きにその場でフィードバックするための Claude Code のプラグイン (Claude Mod) です。
Claude Code でしか動きません。
プラグインのスキル `draft-pane:draft` は、頼まれた下書きを、`draft` というラベルのコードフェンスのブロックの中に Claude に書かせます。
トランスクリプトの横のペインは、まだ開いている下書きのうち最新のものを表示します。
範囲をドラッグしてコメントを入力するか、下書き全体にコメントするか、下書きを承認します。
Submit を 1 回押すと、すべてのコメントを、各範囲を引用した 1 つのプロンプトとして送ります。

## 特徴

- **範囲へのコメント。**
  下書きの範囲をドラッグし、`comment` の入力欄に入力して Enter を押します。
  各コメントは、引用した語句がある行の下に表示されたままになります。
- **下書き全体。**
  `whole draft` は下書き全体に対するコメント欄を 1 つ開きます。
  `Approve` は、下書きをそのまま使ってよいという意味の `(approved)` を送ります。
- **フィードバックは 1 つのプロンプトに。**
  `Submit` は `Feedback (draft-pane) on D3:` を送り、続けて、引用した各範囲を `> ` の行として、その下にコメントを付けて、下書きの中の順に送ります。
  下書き全体へのコメントは最後に送ります。
- **番号付きの下書き。**
  下書きは `D<n>: <title>` で始まり、改訂は `D<m> (revises D<n>): <title>` で始まります。
  番号が再利用されることはありません。
- **ファイルの下書き。**
  見出しの次に `file: <path>` の行があると、既存のファイルを下書きとして表示し、フィードバックのプロンプトにはそのファイルの名前が入ります。
- **トランスクリプトだけで読める。**
  下書きはすべてアシスタントのメッセージの中のテキストで、フィードバックはすべて下書きを引用するプロンプトです。

## エージェントでの使い方

`/draft-pane:draft <what to draft>` で始めるか、Claude に任意の文章の下書きを頼みます。
Claude は下書きを `draft` ブロックに書きます。
フィードバックのプロンプトでは、各コメントが、そのコメントが指す範囲と並んで Claude に届きます。
改訂版は、新しい番号の付いたブロックとして返ってきます。

## はじめかた

draft-pane には、Claude Code 2.1.273 以降と `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` が必要です。

```sh
claude plugin marketplace add meganemura/draft-pane
claude plugin install draft-pane@draft-pane
```

`/draft-pane` はペインの表示と非表示を切り替え、キーボードのフォーカスをペインに移します。
