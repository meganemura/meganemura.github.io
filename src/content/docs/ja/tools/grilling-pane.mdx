grilling-pane は、Claude が計画に取りかかる前に、その計画についてユーザーに質問する Claude Code のプラグイン (Claude Mod) です。
Claude Code でしか動きません。
プラグインのスキル `grilling-pane:grilling` は、質問の進め方として Matt Pocock の `grilling` スキルを呼び出し、各ラウンドの質問を `grilling` というラベルのコードフェンスのブロックに書きます。
grilling-pane はそのラウンドをトランスクリプトの横のペインに表示します。
Submit を 1 回押すと、そのラウンドのすべての回答を 1 ターンで送ります。

## 特徴

- **ボタンになった選択肢。**
  選択肢を押すと選ばれ、もう一度押すと選択が外れます。
  矢印キーでボタン間を移動し、Enter でボタンを押し、Esc でフォーカスをプロンプト欄に戻します。
- **Talk about this one。**
  どの質問にも、最後にこの選択肢があります。
  押すと、空のままでもよい 1 行の入力欄が開き、`(discuss)` と、入力したテキストを送ります。
- **回答は 1 つのプロンプトに。**
  `Submit` は `Answers (grilling-pane):` に続けて質問ごとに 1 行を送り、何も選ばなかった質問には `(skipped)` を送ります。
- **シンプルな質問ブロック。**
  `Q<n>: <question>` の行から質問が始まり、その下の `- ` の行が選択肢です。
  推奨する選択肢は `(recommended: <reason>)` で終わります。
- **トランスクリプトだけで読める。**
  質問はすべてアシスタントのメッセージの中のテキストで、答えはすべて質問を繰り返すプロンプトなので、プラグインがなくてもトランスクリプトを読めます。
- **自動で開くペイン。**
  一度表示すると、それ以降は新しいラウンドが届くたびに、キーボードのフォーカスを奪わずにペインが開きます。
  `/grilling-pane` で隠せます。

## エージェントでの使い方

`/grilling-pane:grilling <plan>` で始めます。
Claude は 1 ラウンド分の質問を `grilling` ブロックに書きます。
質問の番号は、会話全体を通した連番です。
Claude は回答のプロンプトを、そのラウンドへの答えとして読みます。
ラウンドが開いている間にメッセージを入力しても、プラグインはそのメッセージに手を加えません。
Claude は、メッセージで触れなかった質問を、スキップされたものではなく、まだ答えが出ていないものとして扱います。

## はじめかた

grilling-pane には、Claude Code 2.1.280 以降と `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`、そして上流の `grilling` スキルの v1.2.0 以降が必要です。

```sh
gh skill install mattpocock/skills grilling --agent claude-code
claude plugin marketplace add meganemura/grilling-pane
claude plugin install grilling-pane@grilling-pane
```

すべてのセッションでこの変数を設定するには、`settings.json` の `env` に追加します。

```json
{
  "env": {
    "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"
  }
}
```
