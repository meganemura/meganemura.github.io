jira-ticket-pane は、Claude Code のプラグイン (Claude Mod) です。
Claude Code のターミナルセッションでしか動きません。
`/jira DEMO-1` は、セッションに接続済みの MCP サーバーから Jira の課題を 1 つ取得し、トランスクリプトの横のペインに表示します。
取得はプラグインの中で行い、モデルのターンの一部として実行されることはありません。
ボタンを押すと、課題のテキストを次のプロンプトにコンテキストとして添えられます。

## 特徴

- **キーで課題を 1 つ取得。**
  `/jira <KEY>` は課題を取得してペインを開き、`/jira` だけならペインの表示を切り替え、`↻ <HH:MM>` は課題を取得し直します。
  プラグインが定期的にポーリングすることはありません。
- **2 つのタブ。**
  キー、要約、ステータス、タイプ、優先度、担当者を示すヘッダーの下で、`issue` タブは説明を、`meta` タブはフィールドと生の JSON を表示します。
- **コンテキストとして添える。**
  `attach` を押すと課題のテキストを添える準備ができ、ラベルが `attached ✓` に変わります。
  プロンプトを送ると、テキストは外れます。
  プラグインは、プロンプトのコンテキストに使える 32,000 文字の枠のうち、残りに収まるようにテキストを調整します。
- **実行時に見つけるツール。**
  プラグインは、名前に "jira" と "issue"、そして "get"、"fetch"、"read"、"show" のどれかを含む MCP のツールを探します。
  `/jira config server=<name> tool=<name>` でサーバーとツールを固定し、`/jira config clear` で自動で探す方式に戻します。
- **フィクスチャモード。**
  `JIRA_TICKET_PANE_FIXTURE=<dir>` を設定すると、実際の MCP サーバーを呼び出す代わりに `<dir>/<KEY>.json` を読みます。
- **読み取り専用。**
  プラグインは Jira に書き込まず、一度に 1 つの課題を取得し、認証は MCP サーバーに任せます。

## エージェントでの使い方

モデルが課題を目にするのは、添えたときだけです。
`attach` を押すと、課題のテキストが次のプロンプトにコンテキストとして付きます。
収まらないときは行単位で切り詰め、最後に注記を付けます。
取得そのものが、モデルのターンの一部として実行されることはありません。

## はじめかた

jira-ticket-pane には、`CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` を設定した Claude Code と、Jira の課題を読むツールを持ち、セッションに接続された MCP サーバーが必要です。
CI では Claude Code を 2.1.273 に固定しています。

```sh
claude plugin marketplace add meganemura/jira-ticket-pane
claude plugin install jira-ticket-pane@jira-ticket-pane
```

その後、セッションで `/jira <KEY>` を実行します。
