mutation-testing-skills は、ミューテーションテストのための Claude Code のスキルを集めたリポジトリです。
各スキルは 1 つのツールを扱い、セットアップ、実行、結果の読み方、生き残ったミュータントへの対処を、エージェントに順に示します。
ツールに依存しない考え方は、リポジトリのすべてのスキルが使う共有のリファレンスに 1 度だけ書いてあります。

## 特徴

- **`stryker`。**
  JavaScript と TypeScript の StrykerJS のためのスキルです。
  stryker-agent-reporter の出力を読みます。
  stryker-agent-reporter は、Stryker の実行結果を、エージェントがそのまま対処できる生き残ったミュータントの一覧に変換します。
- **`mutineer-practice`。**
  Minitest か RSpec を使う Ruby の mutineer のためのスキルです。
  セットアップと、実際に測定して確かめた落とし穴を扱います。
  CLI とエージェントのループは mutineer 自身の `mutineer` スキルが扱うので、それと組み合わせて使います。
- **共有のリファレンス。**
  `references/` には、ミューテーションテストの考え方が入っています。
  その中には、プルリクエストをその変更自身の差分だけでゲートする方法 (`references/operations.md`) も含まれます。
  インストーラーは各スキルの `references/general` のリンクをディレクトリとしてコピーするので、インストールしたスキルにもこれらが含まれます。
- **スキルの一覧。**
  `npx skills add meganemura/mutation-testing-skills --list` は、リポジトリのスキルを表示します。

## エージェントでの使い方

エージェントは、Stryker をセットアップし、ミューテーションスコアを読み、生き残ったミュータントを仕分け、実行を速くするために `stryker` スキルを読み込みます。
最初の `mutineer run` の前に Ruby のプロジェクトを調べ、セットアップの落とし穴を避け、生き残ったミュータントを仕分けるときは `mutineer-practice` を読み込みます。

## はじめかた

次のコマンドは、StrykerJS のスキルを、すべてのプロジェクトで使えるように Claude Code にインストールします。

```sh
npx skills add meganemura/mutation-testing-skills --skill stryker -g -a claude-code
```

mutineer のスキルは、まず mutineer の作者によるスキルを URL からインストールし、次にこのリポジトリのスキルをインストールします。

```sh
npx skills add https://davidteren.github.io/mutineer/skill.md -g -a claude-code
npx skills add meganemura/mutation-testing-skills --skill mutineer-practice -g -a claude-code
```

現在のプロジェクトにインストールするときは、`-g` を外します。

## 組み合わせ

- `stryker` スキルは、[stryker-agent-reporter](/ja/tools/stryker-agent-reporter/) のエージェント向けの出力を読みます。
