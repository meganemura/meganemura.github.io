polylinedb は、ローカルのツールとクラウドのエージェントのための、個人用の課題ストアです。
CLI は、作業リポジトリの外にある SQLite ファイル 1 つか、認証付きのクラウド接続のどちらかを使います。
Cloudflare Worker は、D1 を使って同じ操作を HTTP とリモート MCP で提供します。
