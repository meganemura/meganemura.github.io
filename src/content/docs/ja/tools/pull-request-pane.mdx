pull-request-pane は、現在のセッションに関わる GitHub のプルリクエストを、トランスクリプトの横のペインに表示する Claude Code のプラグイン (Claude Mod) です。
Claude Code でしか動きません。
プルリクエストがクローズする Issue と、トランスクリプトで言及された Issue も、項目として並びます。
タイトルや説明の範囲をドラッグしてその範囲にコメントし、Submit でコメントを 1 つのプロンプトとして送ります。
ペインが開いている間、各プルリクエストのチェック、レビューの判定、マージできるかどうかは 60 秒ごとに更新されます。

## 特徴

- **範囲へのコメント。**
  項目のタイトルか説明をドラッグすると、その範囲を引用した `comment` の欄が開きます。
  `overall` の欄には、項目全体への 1 つのコメントを書きます。
- **項目ごとに 1 つのプロンプト。**
  `Submit` は、項目を示すヘッダーを送り、続けて各コメントを、対象のテキストの引用の下に付けて送ります。
  全体へのコメントは最後に送ります。
- **一目でわかるチェック。**
  各プルリクエストには、`failing`、`running`、`passing`、`no checks` のいずれか 1 語が表示されます。
  `▶ checks` を開くと、要約の行と、各チェックが、その実行へのリンク付きで表示されます。
- **好きなときに更新。**
  `↻ refreshed <time>` のボタンは、すべての項目のタイトル、説明、チェックをすぐに取得し直します。
  選択中の範囲、コメント、未送信のテキストがある項目は、タイトルと説明が更新されなくなります。
  そのため、Submit を押す前に、コメントが引用しているテキストが変わることはありません。
- **再読み込みの後も残る項目。**
  ペインはデータをプラグイン自身のストレージに保存するので、再読み込みしても、最後に取得した項目がすぐに表示されます。

## エージェントでの使い方

エージェントはレビューを 1 つのプロンプトとして受け取ります。
各コメントは対象のテキストの引用とともに届き、全体へのコメントは最後に届きます。

## はじめかた

pull-request-pane には、Claude Code 2.1.273 以降と `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`、そして GitHub にログインした `gh` が必要です。

```sh
claude plugin marketplace add meganemura/pull-request-pane
claude plugin install pull-request-pane@pull-request-pane
```

`/pull-request-pane` と入力すると、ペインの表示と非表示が切り替わります。
function hooks の API は Claude Code のリリースごとに変わることがあるので、README はこのプラグインを早期アクセス版と位置付けています。
