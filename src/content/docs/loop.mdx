These tools aim at one picture: a development loop that an agent runs from end to end, while a person decides what the software is for and answers the decisions that cannot be undone.
This page draws that loop in six stages and places each tool at the stage it serves.
A stage with a dashed border has no tool on this site yet.

## What the picture shows

The tools so far sit in the first three stages, and most of them in verification.
That is where an agent's mistakes are cheapest to catch, because a check there is a command it can run again in seconds.
The right side of the loop is open: nothing here yet carries a change through staging and production, or tells an agent what happened there.
That is where the next tools go.

The tools also run on each other, and [how the tools fixed each other](/dogfooding/) records what that found.
