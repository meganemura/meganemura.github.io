stryker-agent-reporter is a Stryker reporter for a coding agent.
It writes JSON Lines with one line per surviving mutant, carrying its location, the original and replacement text, a ready-to-apply patch, and a rerun command.
Two more commands, convert and gate, work from that output alone.
